# Ecommerce API (Spring Boot + MySQL + JWT + Wompi)

## Requisitos
- Java 17, Maven 3.9+
- MySQL 8 (crear DB `ecommerce`)
- Edita `src/main/resources/application.yml` (credenciales MySQL y llaves Wompi)

## Ejecutar
```bash
mvn spring-boot:run
```

Swagger: http://localhost:8080/swagger-ui/index.html
